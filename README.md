# Projeto de tranca automática via reconhecimento fácial através do arduino 
## Projeto institucional para a matéria de robôs móveis inteligentes
### Descrição:
Utilizamos uma interface de da intelbrás que utiliza inteligência artifical para fazer o reconhecimento de rostos pré-cadastrados em sua memória para trancar e destrancar uma porta utilizando componentes eletrônicos e principalmente o arduíno para conectar as repostas interface com a tranca, abrindo e trancando a porta com base nos resultados enviados.
